# NONGSKUY


### Aplikasi apa ini ?

nongskuy adalah aplikasi sosial traking dimana pengguna satu dengan pengguna lain dapat saling berkomunikasi dalam satu ruang lingkup

### Siapa yang cocok menggunakan ini ?

nogskuy cocok digunakan sebagai alat komunikasi antar pengguna dalam ruang linkup terbatas, seperti:

- mahasiswa
- pelajar
- pekerja kantoran
- teman harian

### Mengapa menggunakan nogskuy ?

nongskuy merupakan aplikasi traking sosial media dengan ruang linkup terbatas. hal ini yang memedakan nongskuy dengan aplikasi lain. kita dapat mengatur siapa saja yang masuk kedalam ruang linkup tersebut, 2 orang ,5 orang atau bahkan lebih. pada dasarnya nongskuy merupakan aplikasi kusus untuk dilingkungan mahasiswa, hal ini berangkat dari sebuah kasus masalah nyata dalam lingkungan universitas : **"mahasiswa baru sulit untuk mencari kenalan, selain itu mahasiswa lama sulit untuk menambah relasi"**. nongskuy kemudian datang sebagai solusi awal untuk kasus tersebut

### Bagaimana cara menggunakannya ?

Dikarnakan dasar dari aplikasi nongskuy merupakan jawaban dari masalah universitas kami, bentuk rilis aplikasi ini tidak bisa digunakan di semua tempat - **sebab perlu penyesuaian dibagian autentikasi & login**

ada 2 opsi yang bisa pengguna terapkan:

- download file apk secara langsung - **khusus mahasiswa kami**
- memodifikasi source code dari nongskuy dan melakukan penyesuaian penggunaan - **TIDAK UNTUK DIPERDAGANGKAN !**

### Fitur apa yang ada pada nongskuy ?
 
- traking lokasi
- pesan antar pengguna
- grup yang dapat di isi oleh bebeerapa pengguna
- pengaturan sistem yang dapat menyesuaikan UI
- kalkulator Split Bill
- dan lainnya
